# Analysis and Decision Support Interface for Fantasy Cycling Games

## Context
Fantasy cycling games consist in selecting a team of riders under a limited budget
in order to maximize the points scored during a multi-stage race (e.g. Tour de France).
Some games allow transfers between stages, possibly under additional constraints.

## Objective
The objective of this project is to develop tools for post-optimal analysis, assuming
that all performances are known a posteriori. We study how the optimal team evolves
stage by stage under budget and transfer constraints.

## Data
The project relies on real data from the Tour de France 2025:
- Riders' prices
- Points scored per stage
- General classification and jerseys
